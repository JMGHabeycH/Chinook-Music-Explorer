# Chinook Music Explorer

A Python console application for searching songs and exploring best-selling tracks and albums using the Chinook SQLite database.

## Features

- Search songs by name
- View best seller songs
- View best seller albums
- Query data from the Chinook SQLite database
- Display results in the console using pandas

## Technologies Used

- Python
- SQLite
- SQLAlchemy
- pandas

## Project Structure

```bash
Project/
├── main.py
├── services.py
├── database.py
├── Chinook_Sqlite.sqlite
└── README.md
```

## Usage

Run the application with:

```bash
python main.py
```

Then choose an option from the console menu to search songs or view best-selling songs and albums.

## Notes

- The project uses the Chinook sample SQLite database.
- Results are shown directly in the terminal.
